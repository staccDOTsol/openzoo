This page is on Solana.

You are reading bytes out of a Solana account. Every button below runs a function that was a Vercel Lambda and is now an instruction of a Pinocchio program. No server holds this site.

What you are looking at

openzoo-transmute takes an app shaped for Vercel (Next.js pages/api, the app router's route.ts, or a Vite repo with api/*.js) and re-hosts it on Solana mainnet:

Vercel termSolana term
Lambda (*.func)a route in one Pinocchio program (Rust, generated from your handler)
node-bridge Invoke event {method, path, headers, body}instruction data
bridge response {statusCode, headers, body}return data + log chunks

POST / PUT / DELETEa signed transaction
@vercel/kvprogram-derived accounts, discovered by dry run
static/asset accounts (this HTML is one)

maxDuration, memorycompute-unit limit, heap frame
deployment URLa program id + any gateway (this one, or npx openzoo serve on your laptop)

Summary: it is a permanent, permissionless, verifiable host for small stateful APIs and static frontends, not a general web platform. If your app needs the network, secrets, streaming, or heavy compute, it stays on Vercel; if what it needs is to exist forever and be readable by anyone for free, it belongs here.



Put your own app here


npx openzoo inspect .                       # your app, in Vercel terms + what is eligible
npx openzoo build .                         # Rust program + asset plan (needs cargo-build-sbf)
npx openzoo deploy . --cluster mainnet --yes   # rent quoted first; paid by ~/.openzoo/wallet.json
# → https://sites.openzoo.fun/s/<programId>
npx openzoo serve <programId>                # local gateway that signs writes with your wallet


Eligible today: handlers using query/body/headers, JSON, string and array methods, @vercel/kv, Date.now(), process.env. Not eligible: network calls, the filesystem, Math.random, streaming, waitUntil, ISR, middleware. Bodies must fit in one transaction (~900 bytes), responses in the log buffer (~8 KB). Reads are free; writes cost a transaction fee plus rent for new KV accounts.



Where this is going


Writes through the hosted gateway will be paid per request over x402 from the openzoo proxy, at twice cost; adding a site costs a 0.1 SOL dev fee and updating one 0.05 SOL, and those fees are swapped half into TOKEN and paired as SOL/TOKEN liquidity on PumpSwap. A sol:// scheme in a browser fork makes the gateway optional.
